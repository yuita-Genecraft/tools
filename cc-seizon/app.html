AI 開発ログマップ

Claude Code・Codex・Antigravity の会話ログを、このページに落とすだけ。文脈とトークンでは、使用量のどれだけが長い文脈の応答に行ったか（応答の数との差）と、間をあけて再開した時に何が起きたかを、ログだけで数えます。コードの手直しでは、手元のプロジェクトのフォルダも入れて、AI が書いた行のその後（残った・AI が自分で書き直した・ログの外で変わった・ファイルごと消えた）と、書き直しが集中した所、繰り返した直しの型を出します。

ブラウザの中だけで突き合わせ通信なし無料

1AI のログ

Claude Code の ~/.claude/projects・Codex の ~/.codex/sessions・Antigravityの ~/.gemini をここにドロップ。別の AI のログを続けて入れると足します

未読込

ログの場所と開き方
  1. Mac は「ターミナル」に貼って Enter。ログのフォルダが Finder で開きます。 open ~/.claude/projects
  2. Windows はエクスプローラーのアドレス欄に貼って Enter。 %USERPROFILE%\.claude\projects
  3. 開いた projects フォルダを、そのままこのページにドラッグします（「フォルダを選ぶ」で指定しても読めます）。
  4. Codex は open ~/.codex/sessions、Antigravityは open ~/.gemini で開いて、同じ枠にドラッグします。.gemini の中の会話ログは隠しフォルダ（.system_generated）の下にあります。「フォルダを選ぶ」で記録が見つからない時は、ドラッグで入れてください。

Claude Code は古いログを自動で消します（初期設定は30日）。測れるのは、手元に残っているログの期間に AI が書いた分だけです。

2プロジェクトのフォルダ

AI と作業したリポジトリのフォルダをここにドロップ（「コードの手直し」で使います）

未読込

node_modules・.git・ビルド成果物・画像などは読みません。ファイルの中身は端末の外に出ません。スマホのブラウザではフォルダを選べないので、PC で開いてください。

読み込み中

見本架空のデータで表示しています。AI のログを入れると、あなたの数字に変わります。

Xに投稿する
数だけ保存します（行の中身は入りません）。CLAUDE.md を直した後に測り直して、減ったかを見るために。

画像は長押し（スマホ）か右クリック（PC）で保存できます。Xには画像を添えて投稿してください。

ログとファイルはブラウザの中で読み、数えた結果だけを画面に出します。このページはサーバーと通信しません。

「AI が書いた行」は、Claude Code の Edit・Write、Codex のファイル変更（FileChange）、Antigravity の write_to_file・replace_file_content で新しく入った行です。シェルのコマンド（ヒアドキュメントなど）で書かれた行や、ログの期間より前に書かれた行は数えません。
