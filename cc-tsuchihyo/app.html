Claude Code 通知表

Claude Code が手元に残しているログを、このページに落とすだけ。「おっしゃる通りです」と言われた回数、謝られた回数、API のトークン料金に換算した金額までを、通知表にして返します。

ログのフォルダを、ここにドロップ

ログの場所と開き方
  1. Mac は「ターミナル」に貼って Enter。ログのフォルダが Finder で開きます。 open ~/.claude/projects
  2. Windows はエクスプローラーのアドレス欄に貼って Enter。 %USERPROFILE%\.claude\projects
  3. 開いたフォルダの中身をすべて選んで（⌘A か Ctrl+A）、このページにドラッグします。「フォルダを選ぶ」で projects フォルダを指定しても読めます。

Claude Code は古いログを自動で消します（初期設定は30日）。通知表の期間は、手元に残っている分です。設定を変えている場合は ~/.config/claude/projects にあることもあります。

読み込み中

見本架空のデータで表示しています。ログを入れると、あなたの通知表に変わります。

Xに投稿する

画像は長押し（スマホ）か右クリック（PC）で保存できます。Xには画像を添えて投稿してください。

ファイルはブラウザの中で1行ずつ読み、数えた結果だけを画面に出します。このページはサーバーと通信しません。

APIトークン料金換算は、Anthropic が公開している API 料金表（2026年9月29日時点）のトークン単価で計算した目安です。Web検索などのサーバー側ツールの料金は含みません。Pro や Max などの定額プランで使っている場合、実際の請求額とは違います。

ログには同じ応答が複数行に分かれて記録されるため、応答のIDで重複を除いてから数えています。
