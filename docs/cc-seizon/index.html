Claude Code 生存率

Claude が書いたコードのうち、今も残っている行はどれだけか。Claude Code のログと、手元のプロジェクトのフォルダを、このページに落とすだけ。「残った」「Claude が自分で書き直した」「人が消した」に分けて、1枚の画像にします。

1Claude Code のログ

~/.claude/projects のフォルダをここにドロップ

ログの場所と開き方
  1. Mac は「ターミナル」に貼って Enter。ログのフォルダが Finder で開きます。 open ~/.claude/projects
  2. Windows はエクスプローラーのアドレス欄に貼って Enter。 %USERPROFILE%\.claude\projects
  3. 開いた projects フォルダを、そのままこのページにドラッグします（「フォルダを選ぶ」で指定しても読めます）。

Claude Code は古いログを自動で消します（初期設定は30日）。測れるのは、手元に残っているログの期間に Claude が書いた分だけです。

2プロジェクトのフォルダ

Claude Code で作業したリポジトリのフォルダをここにドロップ

node_modules・.git・ビルド成果物・画像などは読みません。ファイルの中身は端末の外に出ません。スマホのブラウザではフォルダを選べないので、PC で開いてください。

読み込み中

見本架空のデータで表示しています。ログとフォルダを入れると、あなたの生存率に変わります。

Xに投稿する

画像は長押し（スマホ）か右クリック（PC）で保存できます。Xには画像を添えて投稿してください。

ログとファイルはブラウザの中で読み、数えた結果だけを画面に出します。このページはサーバーと通信しません。

「Claude が書いた行」は、Claude Code の Edit・Write で新しく入った行です。Bash のコマンド（ヒアドキュメントなど）で書かれた行や、ログの期間より前に書かれた行は数えません。
